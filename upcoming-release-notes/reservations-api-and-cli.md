Add `getReservations(month)` to the API, and `actual reservations list <month>`
and `actual reservations claims <month>` to the CLI. Both return each category
balance divided into reserved, allowance and spare, with the claims behind those
values. You can now read what a category owes from a script, not only in the
app.
